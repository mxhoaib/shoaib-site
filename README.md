# Shoaib Hussan – Fiverr promo site

Static site for Shoaib Hussan (CAD drafter, Fiverr: https://www.fiverr.com/mxhoaib, email mxhoaib0@gmail.com).

Build: `python3 -m pip install markdown && SITE_URL=https://mxhoaib.github.io/shoaib-site python3 build.py`
Posts: add Markdown files to `posts/` (optional `canonical` front matter) and rebuild. `build.py` writes pages in place.
