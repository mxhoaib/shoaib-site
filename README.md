# Shoaib Hussan – Fiverr promo site

Static site for Shoaib Hussan (CAD drafter, Fiverr: https://www.fiverr.com/mxhoaib, email mxhoaib0@gmail.com).

Build: `SITE_URL=https://mxhoaib.github.io/shoaib-site python3 build.py`
Posts: add Markdown files to `posts/` and rebuild. Optional front matter `canonical:` sets `<link rel="canonical">` to that original URL.
